二叉树递归的三种传播模式

一道题属于哪种模式，只看题目问的是什么。递归里信息向下靠参数、向上靠返回值；三种模式的差别，就是子节点往父节点返回什么、以及要不要短路。

一、存在性（OR）
有没有 · 是否存在 · 能否找到
有没有
二、全部满足（AND）
是否全部 · 是否对称 · 是否合法
是不是都
三、聚合（计算型）
多少条 · 最大最小 · 总和
有多少

一、存在性（OR）「有没有」

存不存在一条路径 / 能不能找到 / 是否符合条件。任一子为 true 父就为 true，找到即停，true 沿回溯直线传回根。

二、全部满足（AND）「是不是都」

是不是所有节点都满足 / 左右是否对称 / 整棵树是否合法。任一子为 false 父就为 false，违规即停，false 直线冒泡。与 OR 唯一区别是短路方向。

三、聚合（计算型）「有多少 / 最大是多少」

计数、求和、最大最小。两个子的结果都要用、不能短路；难点是「答案」和「返回值」是两套不同的东西。

聚合型难点：为什么返回值不能分叉？

答案 ans：左右都能走（分叉）

ans = Math.max(ans, l + n + r)，整条折线都算，允许在 n 处拐弯。

返回值：只能选一边（直线）

return n + Math.max(l, r)，只交较大的单边。父节点会把它当成一条直路，再接上另一侧；若传上去的是折线，拼起来就分叉两次了。

混合型：236 最近公共祖先

它既是「找到节点」（OR 语义），又要「返回候选节点」（不是布尔）。两边都要访问（像聚合），但逻辑是哪边找到用哪边（像 OR）。

两边都算，再根据左右是否为空决定返回

判断依据：只要父节点需要同时观察左右两个孩子，就不能短路。因为必须知道「两边是否都有」，才能区分返回孩子还是返回自己。
