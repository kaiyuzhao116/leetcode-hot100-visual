电话号码的字母组合：
按数字位逐层选字母

题目：数字串只含 2–9，每个数字对应几个字母，返回所有字母组合。你的写法用 map 数组存数字到字母的映射，index 表示处理到第几位，走到末尾（叶子）才收集一个完整字符串。下面把每一位能选哪些字母、当前在哪一层都标出来。

输入数字串（金色＝当前处理位，蓝色＝已处理）
当前数字对应的字母候选

当前路径 path（StringBuilder）

当前位置 index / 数字

已收集组合 res

你的代码（当前执行行高亮）

class Solution {
    String[] map = {"","","abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"};
    StringBuilder path = new StringBuilder(); 
    List<String> res = new ArrayList<>();
    public List<String> letterCombinations(String digits) {
        bracktracing(digits,0);
        return res ;
    }
    public void bracktracing(String digits,int index){
        if(digits.length() == index){
            res.add(path.toString());
            return;
        }
        String teters = map[digits.charAt(index) - '0'];
        for(int i = 0 ;i<teters.length();i++){
            path.append(teters.charAt(i));
            bracktracing(digits,index+1);
            path.deleteCharAt(path.length()-1);
        } 
    }
}

看图抓三个点

  • 一层对应一个数字：第 index 层只在该数字的字母里选。
  • 叶子才收集：选满 digits.length 个字母就是一个答案。
  • 组合数＝乘积：各位字母数相乘，如 2(3)×3(3)=9。

数字 → 字母映射（金色＝当前层数字）

复杂度：设组合总数为 N（各位字母数乘积），每个组合长度为 digits 长度 L，构造并拷贝字符串约 O(N × L)；递归栈与 path 深度为 O(L)。
边界提醒（空串）：当前代码对 digits = "" 会走进终止分支，收集一个空字符串，返回 [""]；而题目要求空输入返回 []。可在方法开头加一句 if(digits.length()==0) return res;（此时 res 还是空列表）即可。本可视化忠实展示了代码的真实行为，用例里的空串可以看到这一点。
为什么用 index 而不是循环数字本身：递归每深入一层 index 加 1，正好对应「处理下一位数字」；同一层的 for 循环变量 i 只负责在当前数字的字母里挑一个，两者分工不同，不要混淆。
