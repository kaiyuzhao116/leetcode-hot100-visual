HashSet API 速查

实现 Set 接口 · 元素不重复 · 无序 · 增删查平均 O(1)。下面是可动手操作的演示器，右侧方法的返回值模拟 Java 行为。

操作日志（方法调用 → 返回值）

API 速查表

方法作用返回值
add(E e)添加元素，已存在则不添加boolean：原本没有才 true
remove(Object o)删除指定元素boolean：存在并删除才 true
contains(Object o)是否包含某元素boolean
size()元素个数int
isEmpty()是否为空boolean
clear()清空所有元素void
去重：重复 add 同一元素不报错，第二次返回 false，集合里仍只有一份。
为什么用 contains：哈希查找 O(1)，比遍历 List 的 O(n) 快。
无序：不保证遍历顺序，也没有 get(i) 下标。

Java 代码示例

import java.util.*; public class Demo { public static void main(String[] args) { Set<Integer> set = new HashSet<>(); set.add(1); // true set.add(2); // true set.add(1); // false，重复，不添加 set.contains(2); // true set.size(); // 2 set.remove(1); // true set.isEmpty(); // false set.clear(); // 清空 } }
