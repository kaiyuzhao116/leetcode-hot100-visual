为什么用 while？一面高右墙可能连续弹出多个槽底，逐层向外结算。
为什么栈空就 break？弹出后没有左墙，水会从左侧流走，不能计算。
为什么高度取 min？水位不能超过较矮的墙，再减去槽底才是新增水层。
查看完整 Java 代码
class Solution {
    public int trap(int[] height) {
        int ans = 0;
        Deque<Integer> stack = new ArrayDeque<Integer>();
        int n = height.length;
        for (int i = 0; i < n; ++i) {
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int top = stack.pop();       // 槽底
                if (stack.isEmpty()) {
                    break;                  // 没有左墙
                }
                int left = stack.peek();     // 左墙
                int currWidth = i - left - 1;
                int currHeight = Math.min(height[left], height[i]) - height[top];
                ans += currWidth * currHeight;
            }
            stack.push(i);
        }
        return ans;
    }
}
