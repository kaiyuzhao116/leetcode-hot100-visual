搜索插入位置：闭区间二分，
找不到就返回 left

题目：给定排序数组和目标值，找到目标返回索引；不存在则返回它按顺序应插入的位置，要求 O(log n)。你的写法用 left/right 组成闭区间，每次取中点 mid 比较，命中返回 mid，否则收缩区间；循环结束 left 就是插入位置。

class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0;
        int right = nums.length-1; 
        while(left <= right){
            int mid = left + (right - left)/2;
            if(nums[mid] == target){
                return mid;
            }else if(nums[mid] > target){
               right = mid-1;
           }else{
               left = mid +1;
           }
       }
       return left; 
   }
}

看图抓三个点

  • 闭区间 [left,right]：两端都还可能是答案。
  • mid 防溢出：left+(right-left)/2 不直接相加。
  • 返回 left：循环结束它正指向第一个 ≥ target 的位置。
复杂度：每次区间约减半，最多 ⌈log₂(n+1)⌉ 次比较，时间 O(log n)；只用固定几个指针，辅助空间 O(1)。
为什么找不到时返回 left：循环条件是 left<=right，退出时必有 left=right+1。整个过程中 left 左侧的元素都小于 target，right 右侧的元素都大于 target，所以 left 正好是「第一个不小于 target」的位置——命中时是目标索引，没命中时就是插入点，两种情况统一成一个返回值。
收缩为什么用 mid±1：闭区间里 mid 已经比较过且不等于 target，新区间就不必再包含它，所以用 right=mid-1 或 left=mid+1；若写成 right=mid 会和闭区间语义冲突，可能漏判或死循环。
