HashSet API 速查

最长连续序列里用它存所有数字，靠 contains 做 O(1) 查询。元素不重复、无序、允许一个 null、底层基于 HashMap。

一、特点

只存元素，不存键值对
元素唯一，重复 add 无效
不保证遍历顺序
允许一个 null

二、核心方法（蓝色 = 本题用到）

方法作用返回 / 说明本题
add(e)加入元素boolean；已存在返回 false，不重复加建集合
contains(e)是否包含该元素boolean，O(1)查 num±1
remove(e)删除元素boolean；不存在返回 false
size()/isEmpty()元素个数 / 是否空—
clear()清空—
iterator()取迭代器遍历顺序不固定

三、交互演示

add 已存在的元素不会有任何变化，也不报错——这就是"去重"。本题数组里的重复数字就是这样被去掉的。

最长连续序列场景：判断起点

点"加载"先建集合，再填 num（如 1 或 4），判断它是不是起点。
