子集 II：有重复数字时
怎么不收集到重复子集

题目：数组可能含重复元素，返回所有不重复的子集。你的写法先 Arrays.sort 排序，进入节点照常收集，再用 index 控制起点 + 同层相邻同值跳过去重。下面把每个候选能不能选、为什么跳过都标出来，建议直接点自动播放。

class Solution {
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        List<Integer> path = new ArrayList<>();
        backtracing(nums,path,0);
        return res;    
    }
    public void backtracing(int[] nums,List<Integer> path, int index){
        res.add(new ArrayList<>(path));

        for(int i = index;i<nums.length;i++){
            if(i>index && nums[i-1]==nums[i]){
                continue;
            }
            path.add(nums[i]);
            backtracing(nums,path,i+1);
            path.remove(path.size()-1);
        }
    }
}

看图抓三个点

  • 先排序：相同数字相邻，才能用相邻比较发现重复。
  • 同层去重：i>index 且跟前一个同值，说明是平行重复分支，跳过。
  • 不同层不误杀：i==index 是本层第一个，即使和上层同值也保留。
重点 · 同层去重
同层去重：当 i > index（同层里、不是第一个）且跟前一个同值，就说明这是一条会产生重复子集的平行重复分支，直接 continue 跳过。 if (i > index && nums[i-1] == nums[i]) { continue; } 一句话：同一层里相同的值只让第一个走，后面的全部拦掉；不同层（i == index）不受影响。
复杂度：设去重后子集数为 S（S ≤ 2^n），每个子集拷贝长度不超过 n 的 path，时间 O(n × S)；排序 O(n log n)，递归栈与 path 占 O(n) 辅助空间。
为什么用 i>index 而不是 i>0：index 是本层起点，i>index 表示「同层里、不是本层第一个」。本层第一个位置（i==index）即使值和上层相同也必须保留——它代表的是新一层的选择；只有同层后面再出现相同值，才是会产生重复子集的平行分支，要跳过。
和全排列 II 去重的关系：思路一致，都是「排序 + 同层相同值只留第一个」。全排列用 used[i-1]==false 判断前一个同值是否空闲，这里因为有 index 限定起点，直接用 i>index 就表达了同样的意思，写法更简洁。
