API 方法矩阵

操作头部（失败抛异常）头部（失败返 null/false）尾部（抛异常）尾部（返 null/false）
插入addFirstofferFirstaddLastofferLast
移除removeFirstpollFirstremoveLastpollLast
查看getFirstpeekFirstgetLastpeekLast
两组差异：add/remove/get 在空队列操作时抛 NoSuchElementException；offer/poll/peek 不抛异常，返回 null 或 false。
当栈：push=addFirst、pop=removeFirst、peek=peekFirst（只用头部）。
当队列：offer=addLast（尾部进）、poll=removeFirst（头部出）。
不允许 null 元素；ArrayDeque 基于可变数组，无固定容量，offer 一般不会失败。
