四、完整常用 API

StringBuilder sb = new StringBuilder("abc");

sb.append("def");        // 末尾追加 → "abcdef"
sb.insert(1, "X");       // 位置1插入 → "aXbcdef"
sb.delete(1, 3);         // 删除[1,3)区间
sb.deleteCharAt(0);      // 删除位置0
sb.setCharAt(0, 'Z');    // 替换位置0
sb.reverse();            // 反转
sb.charAt(0);           // 取位置0字符
sb.length();             // 长度
sb.toString();           // 转 String
sb.setLength(0);         // 清空（复用对象）

五、为什么用 StringBuilder 而不是 String

String（不可变）

  • 每次 + 都 new 新对象
  • 原对象被丢弃，浪费内存
  • 无法删除最后一个字符
  • 不适合频繁增删

StringBuilder（可变）

  • append 直接改原对象
  • 全程一个对象，可复用
  • deleteCharAt 轻松撤销
  • 回溯/拼接场景首选
