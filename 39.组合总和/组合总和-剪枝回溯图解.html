组合总和：数字可重复选，
sum 超了就剪枝

题目：数组无重复元素，找出所有和为 target 的组合，同一个数字可以无限次使用。你的写法用成员变量 sum 记当前和，递归时传 i（不是 i+1）实现重复选；sum>target 直接返回剪枝，sum==target 收集。下面把每次加和、剪枝都标出来。

class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    int sum = 0;
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        
        
        backtraking(candidates,target,0);
        return res;

    }
    public void backtraking(int[] candidates,int target,int index ){
        if(sum > target){
            return;
        }
        if(sum == target){
            res.add(new ArrayList<>(path));
            return;
        }
        for(int i = index ;i < candidates.length;i++){
            sum = sum + candidates[i];
            path.add(candidates[i]);
            backtraking(candidates,target,i);
            path.remove(path.size() -1);
            sum = sum -candidates[i];    
        }
    }
}

看图抓三个点

  • 递归传 i：同一数字能反复选，传 i+1 就只能用一次。
  • sum>target 剪枝：正数再加只会更大，此路不通直接返回。
  • 双变量一起回溯：path 撤销、sum 减回，缺一不可。
复杂度：设实际搜索到的节点数为 K（含被剪枝的分支），每个节点做 O(1) 加和与拷贝，时间约 O(K)；递归栈深度不超过 target（最小元素为 1 时），辅助空间 O(target)。若先排序还能在同层更早剪枝，但当前写法不排序也正确。
为什么递归传 i 而不是 i+1：题目允许同一数字无限次使用，传 i 让下一层仍能从当前这个数字开始选（包括再选它自己）；index 则保证组合按「不回头」的顺序生成，避免 [2,3] 和 [3,2] 这样的重复。
