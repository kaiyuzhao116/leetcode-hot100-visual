分割回文串：每一刀
都先确认是回文再切

题目：把字符串切成若干子串，使每段都是回文，返回所有分割方案。你的写法在切割起点 index 上，逐个尝试终点 i，用 isHuwan 双指针判断 s[index..i] 是否回文：回文才切并递归 i+1，不回文就跳过；走到末尾收集一种方案。

class Solution {
    List<List<String>> res = new ArrayList<>();
    List<String> path = new ArrayList<>();

    public List<List<String>> partition(String s) {
        backtracing(s,0);
        return res;
    }
    public void backtracing(String s,int index){
        if(index == s.length()){
            res.add(new ArrayList<>(path));
        }
        for(int i = index;i<s.length() ;i++){
            if(isHuwan(s,index,i)){
                path.add(s.substring(index,i+1));
                backtracing(s,i+1);
                path.remove(path.size()-1);
            }
        }
    }


    public boolean isHuwan(String s,int left ,int right ){
        while(left<right){
            if(s.charAt(left) != s.charAt(right)){
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}

看图抓三个点

  • 双指针夹逼：两端字符相等才往里缩，不等立即判否。
  • 回文才切：不回文的子串根本不进递归，天然剪枝。
  • 递归传 i+1：切完这段，下一刀从 i 的后面开始。
复杂度：设字符串长度为 n。最坏（如全相同字符）分割方案数接近 2^(n-1)，每段还要 O(n) 判断回文与拷贝，时间上界约 O(n × 2^n)；递归栈与 path 占 O(n)。若用 DP 预处理所有区间的回文性，可把每次判断降到 O(1)。
substring 的边界：s.substring(index,i+1) 第二个参数是不包含的位置，所以要写 i+1 才能取到第 i 个字符；这和双指针闭区间 [index,i] 是同一段，别因为 +1 误以为多取了一个字符。
