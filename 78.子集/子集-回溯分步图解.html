子集：每个节点
本身就是一个答案

题目：元素互不相同，返回所有子集（幂集）。你的写法里 backtracking 一进入就把当前 path 存进结果，再用 index 控制 for 的起点，每个元素只在更深层出现，天然不重复。下面把每一步画出来，建议直接点自动播放。

你的代码（当前执行行高亮）

class Solution {
    List<List<Integer>> res = new ArrayList<>();
    public List<List<Integer>> subsets(int[] nums) {
        List<Integer> path = new ArrayList<>();
        bracktracing(nums,path,0);
        return res;

    }
    public void bracktracing(int[] nums,List<Integer> path,int index){
        res.add(new ArrayList<>(path));

        for(int i = index;i<nums.length;i++){
            path.add(nums[i]);
            bracktracing(nums,path,i+1);
            path.remove(path.size() -1);
        }
    }
}

看图抓三个点

  • 每个节点都收集：一进 backtracking 就 add，所以根的空集也在里面。
  • index 防重复：本层只从 index 开始选，前面的元素交给更浅的层处理。
  • 递归传 i+1：下一层起点后移，保证子集元素按原顺序、不会回头。
复杂度：子集共 2^n 个，每个子集拷贝长度不超过 n 的 path，时间 O(n × 2^n)；递归栈与 path 占 O(n) 辅助空间，结果集本身占 O(n × 2^n)。
为什么不用 used：全排列关心元素的顺序，同一批元素不同顺序算不同答案，所以要 used 防止重复使用；子集只关心选了哪些元素，用 index 限定起点后每个元素最多被选一次，路径不会重复，无需 used。
空集为什么在最前：根节点 path 为空，进入函数第一行就 res.add(path)，所以空集是第一个被收集的；之后每做一次选择得到一个更长的子集，正好覆盖幂集全部 2^n 种。
