32. 最长有效括号

困难
两种方法都是 O(n) 时间 O(n) 空间 · 可在下方切换

情况1：s[i-1] = '('　形如 ....()

最后两个直接配对，再拼上更前面的长度：
len[i] = len[i-2] + 2（i-2 越界只取 2）

情况2：s[i-1] = ')'　形如 ....))

跨过前面有效子串找左括号：m = i-len[i-1]-1，若 s[m]='(' 则
len[i] = len[i-1]+2+len[m-1]

阶段1：标记配对位置

栈存"未配对左括号的下标"。遇 '(' 压栈；遇 ')' 且栈非空就弹出，把这两个位置 isValid 都标 true。

阶段2：找最长连续 true

遍历 isValid，连续 true 用 cnt 计数、ans 记最大值；遇 false 就 cnt 清零。
