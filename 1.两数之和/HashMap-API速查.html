HashMap API 速查

两数之和里用它存"数组值 → 下标"。key 唯一（重复 put 覆盖），无序，允许 null 键值，非线程安全。

一、特点

键值对 key→value
key 唯一，重复即覆盖
不保证遍历顺序
允许 null 键 / 值

二、核心方法（蓝色 = 两数之和用到）

方法作用返回 / 缺失行为本题
put(k,v)放入或覆盖返回旧值，没有则 null建表
get(k)按 key 取值没有则 null取下标
containsKey(k)是否有该 keyboolean判断补数
getOrDefault(k,d)取值，缺失给默认值缺失返回 d
remove(k)删除该键值对返回旧值，没有则 null
keySet()/values()/entrySet()取所有键 / 值 / 条目集合视图
size()/isEmpty()/clear()大小 / 是否空 / 清空—
