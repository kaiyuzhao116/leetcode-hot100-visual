3. 无重复字符的最长子串

中等
滑动窗口 + HashMap · 时间 O(n) 空间 O(字符集) · 维护一个始终无重复字符的窗口，求窗口最大长度
右指针 i 逐个扫字符，用 map 记录每个字符最近一次出现的下标。一旦当前字符 c 已在窗口内（map 里有它、且旧下标 >= left），就把左指针 left 跳到旧下标 +1，把重复字符移出窗口；然后更新 map 并取窗口长度 i-left+1 的最大值。
