沿四方向 DFS 拼出单词

题目：给定字符网格和单词，判断能否从某格出发，沿水平/竖直相邻格依次拼出单词，同一格不能重复用。你的写法从每个格子作为起点，用 visited 标记，四方向递归，返回前撤销。下面把每一步的匹配、失败原因、回溯都标出来。

class Solution {
    public boolean exist(char[][] board, String word) {
        boolean res = false;
        int x = board.length;
        int y = board[0].length;
        boolean[][] visited = new boolean[x][y];
        for(int i = 0;i<x;i++){
            for(int j = 0 ;j < y;j++){
                if(dfs(board,word,visited,0,i,j)){
                    res = true;
                }
            }
        }
        return res;
        
    }
    public boolean dfs(char[][] board,String word,boolean[][] visited,int index,int i,int j){
        if(word.length() == index ){
            return true;
        }
        if(i<0 || i>= board.length || j<0 || j>= board[0].length || visited[i][j] == true || word.charAt(index) != board[i][j]){
            return false;
        }
        visited[i][j] = true;
        boolean shang = dfs(board,word,visited,index+1,i,j+1);
        boolean xia   = dfs(board,word,visited,index+1,i,j-1);
        boolean zuo   =dfs(board,word,visited,index +1,i-1,j);
        boolean you   = dfs(board,word,visited,index +1,i+1,j);
         visited[i][j] = false;
        if(shang || xia || zuo || you){
            return true;
        }
        
        return false;
    }
}

看图抓三个点

  • visited 防重复：路径上的格子标记，四方向不会绕回自己。
  • 失败即返回 false：越界、已访问、字符不匹配都拦在 mark 之前。
  • 回溯撤销：返回上层前 visited 置 false，格子可被其他路径再用。
复杂度：设网格格子数为 N、单词长度为 L。最坏每个起点都尝试，且每步最多四个方向，时间上界约 O(N × 3^L)（来的方向被 visited 排除，实际分支常远小于此）；visited 数组与递归栈占 O(L) 额外空间。
判断顺序的细节：代码把 word.length()==index 放在最前面，先于越界检查。所以在最后一个匹配格上，四个方向的递归调用会因 index 已等于长度而直接返回 true（哪怕其中一个方向坐标已越界）。结果正确，但可视化里你会看到同一层连出几个「成功」，这正是终止条件优先导致的；若想更严谨，可把越界检查提到终止判断之前。
变量名与实际方向相反：代码里 shang = dfs(i,j+1) 实际是向右，xia = dfs(i,j-1) 向左，zuo = dfs(i-1,j) 向上，you = dfs(i+1,j) 向下。名字对不上但不影响结果，建议改成 right/left/up/down 以免日后误读。
