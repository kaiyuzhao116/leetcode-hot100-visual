PriorityQueue API 速查

基于优先级堆（默认小根堆），不允许 null，自动扩容；堆顶永远是最优先的元素。

一、四种构造方式

new PriorityQueue<>()
默认小根堆，按自然顺序，堆顶最小
new PriorityQueue<>((a,b)->a-b)
lambda 小根堆：a 比 b 小就返回负数，让 a 排前面
new PriorityQueue<>(Collections.reverseOrder())
大根堆，堆顶最大
new PriorityQueue<>((a,b)->b-a)
lambda 大根堆：a 比 b 大时 b-a 为负，让 a 排前面
比较器 compare(a,b) 的返回值决定谁排前面
返回负数（<0）a 排前面，更靠近堆顶
返回 0两者并列
返回正数（>0）b 排前面，a 靠后
数值例子：a=3，b=5。
写 (a,b)->a-b：3-5=-2 为负，3 排前面 → 小的在前，就是小根堆；
写 (a,b)->b-a：5-3=2 为正，b 排前面，等价让大的在前，就是大根堆。

二、核心方法（注意空堆行为）

方法作用空堆 / 失败行为
offer(e)入队并上浮，返回 boolean无界自动扩容，不失败
add(e)同 offer容量满才抛异常（实际不会）
poll()移除并返回堆顶，下沉空堆返回 null
remove()移除并返回堆顶空堆抛 NoSuchElementException
peek()返回堆顶，不移除空堆返回 null
element()返回堆顶，不移除空堆抛 NoSuchElementException
contains(e)是否包含某元素返回 boolean
size() / isEmpty() / clear()大小 / 是否空 / 清空—
