实现 Trie：前缀树
是怎么把单词存进一棵树的

题目：实现前缀树的 insert（插入）、search（精确查找）、startsWith（前缀判断） 三个方法。你的写法是每个节点放一个 26 长度的子节点数组 + isEnd 标记。核心就一句话：顺着字符往下走，没有就新建，走到末尾用 isEnd 标记一个完整单词。下面把每个操作的每一步都画出来，建议直接点自动播放。

class Trie {
    public class Node{
        Node[] chirldren = new Node[26];
        boolean isEnd;
    }
    Node root;

    public Trie() {
        root = new Node();
    }

    public void insert(String word) {
        Node cur = root;
        for(int i = 0; i<word.length();i++){
            int c  = word.charAt(i) - 'a';
            if(cur.chirldren[c] == null){
                Node node = new Node();
                cur.chirldren[c] = node;
            }
            cur = cur.chirldren[c];
        }
        cur.isEnd = true;
    }

    public boolean search(String word) {
        Node cur = root ;
        for(int i = 0;i< word.length();i++){
            int a = word.charAt(i) -'a';
            if(cur.chirldren[a] == null){
                return false;
            }
            cur = cur.chirldren[a];
        }
        return cur.isEnd;
    }

    public boolean startsWith(String prefix) {
        Node cur = root ;
        for(int i = 0;i< prefix.length();i++){
            int a = prefix.charAt(i) - 'a';
            if(cur.chirldren[a] == null){
                return false;
            }
            cur = cur.chirldren[a];
        }
        return true;

    }
}

看图抓三个点

  • 一个节点 = 一个字符；从根走到某节点，沿途拼起来就是一个前缀。
  • isEnd 才是完整单词：search 走完还要看 isEnd，startsWith 只要路径在就返回 true。
  • 共享前缀只存一份：在分叉处复用同一条路径，这正是 Trie 省空间的原因。
复杂度：三个操作都沿字符串走一遍，时间 O(L)（L 为单词/前缀长度）；空间按实际节点数 O(所有单词的字符总数)，每个节点开 26 个槽但只在用到时才挂子节点。
search 和 startsWith 的区别：两者都要先确认整条路径存在；差别在最后——search 还要 return cur.isEnd（路径终点必须是单词结尾），而 startsWith 路径走完直接 return true，不管它是不是完整单词。
为什么子节点用 26 长度数组：题目限定小写字母，charAt(i) - 'a' 直接把字符映射成 0–25 的下标，定位下一个节点是 O(1)；isEnd 单独标记，因为同一个节点可能既是某个单词的结尾，又是更长单词的中间节点。
