19. 删除链表的倒数第 N 个结点 中等

dummy 虚拟头 + slow/fast 双指针一次遍历 · 时间 O(L) · 空间 O(1)

先让 fast 从 dummy 出发先走 n 步，拉开长度为 n 的间隔；再让 slow、fast 一起走，直到 fast 到最后一个节点。此时 slow 的下一个正好是倒数第 n 个节点，用 slow.next = slow.next.next 跳过它即可。dummy 保证了删除头节点时也有前驱可挂。
